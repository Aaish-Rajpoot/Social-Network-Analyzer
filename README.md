# Social-Network-Analyzer
Models a social network using graph structures to represent users and their connections. Supports adding users, creating connections, and listing connections for each user. The system can be extended to analyze the network, find mutual friends, or implement recommendations.

## Description
Models and analyzes a simple social network using graph structures. Users and their connections are managed through OOP.

## Features
- Add users
- Create connections
- Show user friends

## Run
```bash
g++ main.cpp network.cpp -o network
./network
